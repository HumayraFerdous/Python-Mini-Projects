# Python-Mini-Projects
Project - 1
A simple Python project describing my expenditure in September 2024. This project includes my expenditure on a week-by-week, category-wise, and day-wise basis in September. 
Included libraries are pandas, matplotlib, and seaborn.

Project - 2
A simple project on the MovieLens 1M dataset describing movie ratings based on gender.

Project - 3
A short project on the Grocery_Stores dataset focusing on how individual items are bought weekly, the most popular items, gender-wise spending, payment methods, and 
plotting of relationships between items and total_spent. This project questions the best-selling item, busiest day of the week, membership impacts, and age distribution.
